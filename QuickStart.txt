🛠️ Run It in Kali Terminal

1.Make sure you have Python installed:

	sudo apt-get install python3

2.Make sure you have Flask installed:

	pip3 install flask

3.Run the app:

	python3 app.py

4.open the link in your browser:

	http://localhost:5000

5.Enter the credentials in textfields:
Eg:	Username:hacker123
	Password:testpass

6.Click Submit button.

7.In your terminal, you’ll see:

	[+] Captured Credentials -> Username: hacker123, Password: testpass
